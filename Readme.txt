## About the Project
CampusNotes is a simple project designed to organize academic notes subject-wise.

## Features
- Subject-wise notes organization
- Easy access to study material
- Reusable notes template
- Organized folder structure

## Purpose
This project is created as part of the Version Control System assignment to practice Git and GitHub operations.
## Suggested Folder Structure

CampusNotes/
- Mathematics/
- Programming/
- Computer Science/
- General Notes/
- Templates/

## How to Use
1. Create a folder for each subject.
2. Add notes in the relevant subject folder.
3. Copy templates/notes-template.md into your subject folder and fill it in.
4. Keep study material organized by topic.
